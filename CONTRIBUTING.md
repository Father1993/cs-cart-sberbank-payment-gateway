# Contributing

Спасибо за интерес к проекту.

## Перед началом

1. Прочитайте [README.md](README.md) и [SECURITY.md](SECURITY.md).
2. **Не коммитьте** реальные merchant credentials, пароли API, логи, дампы БД, `.env` с секретами.
3. В примерах используйте только фиктивные значения (`example.com`, `MERCHANT_LOGIN_PLACEHOLDER`, `***`).

## Процесс

1. Форкните репозиторий или создайте ветку от `main`.
2. Внесите изменения с понятными сообщениями коммитов (conventional commits приветствуются).
3. Убедитесь, что не попали персональные/корпоративные URL и идентификаторы (см. [docs/release-checklist.md](docs/release-checklist.md)).
4. Откройте Pull Request с кратким описанием мотивации и способа тестирования.

## Стиль кода

- Соответствуйте существующему стилю PHP в аддоне (CS-Cart 4.x).
- Избегайте отладочного вывода (`var_dump`, необоснованный `print_r`) в production-путях.
- Любое новое логирование платёжных данных должно маскировать секреты; см. существующую практику с `password` → `***` в логах запросов.

## Лицензия

Вклад в репозиторий предполагается под той же лицензией, что и проект — см. [LICENSE](LICENSE).
