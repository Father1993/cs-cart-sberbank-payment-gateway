Отправляю ниже информацию про новый шлюз (файлы во вложении при необходимости):
Прямой целевой шлюз Сбербанка – это альтернативное решение для обеспечения работоспособности сервисов интернет-эквайринга, разработанное внутри Банка и обеспечивающее стабильность и надежность операций, а также оперативную техническую поддержку партнера. Документация размещена на dev-portal : https://ecomtest.sberbank.ru/doc
Основные преимущества по сравнению со старым шлюзом РБС:
	Приоритетная разработка и введение новых платежных «фишек», приоритет старого шлюза по сравнению с новым - низкий
	Повышенная техническая конверсия в среднем на 3% (по данным клиентов, которые уже переведены на целевой шлюз)
	Повышенная конверсия обработки фронтальных сценариев в среднем на 5% (по данным клиентов, которые уже переведены на целевой шлюз)
	Возможность кастомизации платежной страницы под фирменный стиль партнера
	Новый Личный Кабинет ИЭ на базе платформы СберБизнес, объединение различных продуктов и управление ими в одном месте
	Приоритетная поддержка в чате во время интеграции и после перехода
	Протоколы являются обратно совместимыми, поэтому затраты на переинтеграцию ожидаются минимальные со стороны партнера
 В рамках подключения на новый шлюз существуют следующие ограничения:
1.	Поддерживается только http POST метод (http GET не поддерживается)
2.	Параметры запроса передаются только в теле JSON-сообщений
3.	Не поддерживается SOAP интерфейс
4.	Используется более строгая пре-валидация запросов согласно схемам
5.	Состав (названия, форматы, структура) и логика обработки максимально приближены к предыдущему решению. Исключения могут составлять собственные сервисы, добавленные для 3DS 2.0
Из отдельных, крайне желательных, нововведений мы просим в рамках регистрации заказа всегда указывать FEATURES (FORCE_SSL/FORCE_FULL_TDS) для стабильности работы запросов при изменении бэкового функционала и строгого маркирования операций по типу SSL/3DS.
1	Функциональность
На данный момент мы можем предоставить следующие возможности:
	Собственная инхаус платежная страница с возможностью кастомизации под фирменный стиль партнера (документация во вложении)
	Личный кабинет ИЭ СББОЛ (ограниченный функционал, документация во вложении)
	Миграция связок со старого решения (если это необходимо партнеру)
	Эмуляция процедуры 3DS1.0 как 2.0
	Банковский MPI (3DS Server)
	Проведение одностадийных платежей с вводом карточных данных на стороне ТСП
	Проведение двухстадийных платежей с вводом карточных данных на стороне ТСП
	Проведение платежей с использованием результатов внешней аутентификации Плательщика по 3-D Secure
	Предоставление сведений о платеже
	Отмена платежа и возврат покупок
	Оплата через мобильное приложение Сбербанк-Онлайн
	Создание и использование автоплатежей (платежей без повторного ввода номера карты)
	SDK SberPay
	Dev-portal (постоянно обновляется и актуализируется) + чат в телеграмме с приоритетной поддержкой партнера
2	Ограничения
На данный момент мы в процессе разработки следующих функциональности:
	Фискализация (пока необходимо осуществлять онлайн-фискализацию партнера на своей стороне). Ориентировочно до середины 3Q2023
	Интеграция со СберСпасибо (необходима прямая интеграция со стороны партнера при необходимости) Ориентировочно до конца 2023 года
	SDK (частично в разработке) – в течение 2 квартала будет готово
	Выставление ссылок на оплату из Личного Кабинета также в разработке (e-invoicung) – в течение 2 квартала будет готово
	Личный Кабинет ИЭ СББОЛ (пока есть возможность делать только действия ниже, презентация во вложении) – функционал постоянно дорабатывается и улучшается в зависимости от потребности партнера.
Возможности ЛК ИЭ:
- Работа с заказами ИЭ и SberPay:
1) поиск по номеру заказа2) детальная информация по заказу3) возможности провести полную/частичную отмену/возврат или завершение для двухстадийного заказа (для роли с правами администратора)
- Работа с терминалами ИЭ и SberPay:1) поиск по номеру терминала (TID)2) детальная информация терминалу и точке - TID, MID, MCC, подключенные пермиссии3) возможность генерации нового пароля от платежного шлюза Сбера для терминала (для роли с правами администратора)
